# Коротко для захисту

## Де використано шаблони
- **Adapter**: `LegacyMathAdapter` приводить інтерфейс старого `LegacyMathEngine` (методи `Sum/Diff/Prod/Quo`) до `ICalculator`, який очікує основна частина програми.
- **Facade**: `CalculatorFacade` дає єдину точку входу для обчислення, вибору режиму, обробки помилок і створення потрібної комбінації об'єктів.
- **Decorator**: `RoundingDecorator` додає округлення, `HistoryDecorator` додає логування історії, не змінюючи код базових калькуляторів.

## Як дотримано SOLID
- **SRP (Single Responsibility Principle)**: кожен клас має одну головну роль: `MainViewModel` керує станом UI, `LightCalculator/FullCalculator` виконують обчислення, `HistoryDecorator` веде історію.
- **OCP (Open/Closed Principle)**: нову поведінку (округлення, історія) додано через декоратори, без змін у `LightCalculator` та `FullCalculator`.
- **DIP (Dependency Inversion Principle)**: `MainViewModel` працює через абстракцію `ICalculatorFacade`, а не напряму з конкретними класами калькуляторів.

## Перевірка правил LightCalculator
У `LightCalculator` реалізовані потрібні правила:
- `A+0=A`, `0+A=A`;
- `A-0=A`, `0-A=-A`;
- `A*0=0`, `0*A=0`;
- `A/B=0`, якщо `A=0` і `B!=0`;
- при `B=0` кидається `DivideByZeroException`.

## Публікація без встановленого .NET (self-contained)
Приклад для Windows x64:

```bash
dotnet publish CalculatorApp/CalculatorApp.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

Пояснення параметрів:
- `-c Release` — збірка в режимі релізу;
- `-r win-x64` — цільова платформа (Windows 64-bit);
- `--self-contained true` — додає .NET Runtime в публікацію;
- `/p:PublishSingleFile=true` — один виконуваний файл (зручно для передачі).
